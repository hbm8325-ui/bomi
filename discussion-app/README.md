# 토의 연습실 · 인문학 그룹 토의(4단계) 연습 웹앱

SK하이닉스 Half-Day Step 4 Group Discussion(인문학 주제 그룹 토의)을 혼자 연습하려고 만든 **비공식 개인 연습 웹앱**입니다.
찬반 토론이 아니라, 정답 없는 주제를 두고 서로 다른 관점을 조율해 **공동 결과물**을 만드는 흐름을 4단계로 연습합니다.
서버 없이 브라우저에서만 동작하고, 내 Gemini API 키(BYOK)로 AI 팀원 세 명과 토의한 뒤 실제 발언·결과물에 근거한 피드백과 꼬리질문을 받습니다.

- SK하이닉스와 아무런 제휴가 없고, 실제 면접 문제·평가·채용 결과와 무관합니다.
- 주제·추가 관점·모범 예시는 연습용으로 새로 만든 것이며, AI 발언과 피드백은 오류가 있을 수 있습니다.
- 아이폰 Safari와 데스크톱 Chrome을 함께 지원합니다.

## 4단계 진행 (총 40분)

| 단계 | 시간 | 내용 |
| --- | --- | --- |
| 1. 개인 의견 준비 | 5분 | 배경·쟁점을 읽고 핵심 입장·기준 / 주요 근거 / 예상되는 다른 관점 메모. 2~4단계에서 접어서 계속 확인 |
| 2. 1차 토의 | 10분 | 민준(원칙·본질) · 서연(사람·현장) · 도현(현실·조율·실행)과 관점 나누고 공통 기준 찾기 |
| 3. 추가 관점 확인 · 2차 토의 | 15분 | 💡 추가 관점 카드가 공개되고, 그 관점을 반영해 결론·예외를 조정 |
| 4. 공동 결과물 작성 | 10분 | 4개 항목 템플릿에 합의안 작성 + AI 팀원 초안/보완 피드백 + 제출 |

- 단계별 타이머(5/10/15/10분)와 `[연습: 다음 단계]` 버튼으로 기다리지 않고 이동할 수 있습니다.
- 입력창에서 예상 발화 시간(분당 약 300자)을 실시간으로 보여 줍니다.

## 기능

| 기능 | 내용 |
| --- | --- |
| 주제 | 8개 카테고리 · 28개 토의 주제(합의·결과물 도출형), 랜덤/목록/직접 입력(추가 관점 포함) |
| 추가 관점 | 모든 내장 주제에 3단계용 `additionalPerspective` 탑재, 3단계 진입 시 화면 상단·타임라인에 공개 |
| 모범 가이드 | 모든 주제에 핵심 관점 3가지 · 30초 첫 발언 · 추가 관점 조율 멘트 · 모범 공동 결과물 예시(📖 시트에서 복사) |
| 팀원 | 민준(원칙·본질) · 서연(사람·현장) · 도현(현실·조율·실행) — 찬반 진영 배정 없이 렌즈만 나눔 |
| 성향 | 합의·조율 토의(기본) / 찬반 집중 토론 선택 |
| 발언 | 1~3문장 구어체 존댓말, 반복 발언 차단, 이름을 부르면 그 팀원이 다음에 답함, 단계별 맥락 전달 |
| 4단계 | 4항목 공동 결과물 에디터, AI 초안 제안(확인 후 반영), 3줄 보완 피드백, 모바일/데스크톱 대화 병행 보기 |
| 피드백 | 논리성·기준 / 관점 수용·조율 / 경청·연결 / 토의·결과물 기여 / 표현력 5개 항목 0~100점, `#U1` 발언 인용, 고쳐 말하기 예시 |
| 꼬리질문 | 내 발언·공동 결과물을 인용한 면접관 꼬리질문 3개 + 1:1 방어 답변 리허설 & 3줄 코칭 |
| 음성 | `webkitSpeechRecognition`(ko-KR) 음성 입력, 멈추고 수정 / 바로 전송, 미지원 시 텍스트 안내 |
| AI 목소리 | `speechSynthesis`로 팀원별 톤·속도를 구분해 읽기(기본 끔, 미지원 환경 안전 폴백) |
| 모드 | 팀원 응답 1명/2명, 일반/실전 표시(실전은 이전 AI 발언을 가림), 응답 간격 여유/보통/빠름, 일시정지·재개 |
| 기록 | localStorage 자동 저장(준비 메모·추가 관점·공동 결과물 포함), 과거 기록에서 API 호출 없이 보기, JSON 백업/복원 |
| 키 관리 | `hd_gemini_api_key`에만 저장, 보기/가리기, 삭제, 연결 테스트로 모델 목록 확인 |

## 빠른 시작

```bash
npm install
npm run dev        # http://localhost:5173
```

1. 오른쪽 위 **설정** → [AI Studio](https://aistudio.google.com/apikey)에서 발급한 `AIza...` 키를 붙여넣습니다.
2. **연결 테스트 & 모델 불러오기**를 누르면 사용 가능한 모델을 읽어 가장 최신 Flash-Lite를 자동 선택합니다.
3. 주제를 고르고 **4단계 토의 시작하기**. 키가 없으면 데모 모드로 4단계 흐름과 예시 초안·피드백을 모두 확인할 수 있습니다.

## 빌드

```bash
npm run typecheck   # tsc --noEmit
npm run build       # tsc --noEmit && vite build → dist/
npm test            # vitest (단위 + 앱 흐름 63개)
```

`vite.config.ts`의 `base: './'` 덕분에 `dist/`는 GitHub Pages 하위 경로
(`https://<user>.github.io/<repo>/`)에서도 그대로 동작합니다.

### PC 실행용 패키지

```bash
python3 work/humanities-debate-pc/build_zip_toi.py   # → downloads/인문학토의_PC실행용.zip
```

`work/humanities-debate-pc/인문학토의_PC실행용/`의 `app/`에 빌드 결과를 넣고, 포트 4173 런처(Windows `.bat`, Mac `.command`)와
`사용방법.txt`를 함께 묶습니다.

### GitHub Pages 배포

1. 저장소를 만들고 이 폴더를 올립니다.
2. `npm run build`로 `dist/`를 만듭니다.
3. `dist/` 내용을 `gh-pages` 브랜치 루트에 올립니다.

```bash
npm run build
npx gh-pages -d dist
```

4. 저장소 Settings → Pages에서 브랜치를 `gh-pages` / `(root)`로 지정합니다.
5. 아이폰 Safari에서 주소를 열고 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
